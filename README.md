# 🧩 Memory Puzzle Game 

An interactive, browser-based **Memory Puzzle Game** developed using Python and **NiceGUI**, created as part of project tasks with **Rhombix Technologies**.

## 🚀 Features
* **Interactive UI:** Clean, responsive web-based interface powered by NiceGUI and Tailwind CSS[cite: 1].
* **Card Matching Logic:** Click-to-reveal mechanics with real-time state updates and smooth mismatch handling.
* **Live Countdown Timer:** Built-in timer challenging players to find all matching pairs before time runs out[cite: 2].
* **Dynamic Score Tracking:** Instantly tracks successfully matched pairs out of total pairs.
* **Win/Loss States:** Clean game-over and congratulatory screens with a restart option.

## 🛠️ Tech Stack
* **Python** (Core Game Logic & Async Handling)
* **NiceGUI** (Python Web Framework)

## ⚙️ Installation & Running Guide

To run this project locally on your machine, follow these steps:

1. **Clone the Repository:**
   ```bash
   git clone [https://github.com/zunairafatima5678-spec/RhombixTechnologies_Memory_Puzzle_Game](https://github.com/zunairafatima5678-spec/RhombixTechnologies_Memory_Puzzle_Game)
   cd RhombixTechnologies_Memory_Puzzle_Game

Install Dependencies:
Make sure you have Python installed, then run the following command to install the required NiceGUI library:

Bash
pip install -r requirements.txt
Run the Game:
Execute the Python script:

Bash
python memory_puzzle_game.py
Play the Game:
Open your web browser and click on the local URL provided in your terminal (e.g., http://localhost:8080 or http://localhost:8082).
